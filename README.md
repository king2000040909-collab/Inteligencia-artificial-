## 📋 Descripción del Proyecto

Este proyecto es una **página web dinámica moderna** que sirve como portal de información para un repositorio de Inteligencia Artificial aplicada a la educación. Fue diseñada pensando en:

- ✨ **Diseño moderno y responsive**
- 🎨 **Interfaz intuitiva y atractiva**
- ⚡ **Rendimiento optimizado**
- 📱 **Totalmente adaptable a móviles**
- 🎯 **Funcionalidad dinámica con JavaScript**

## 🚀 Cómo Usar

### Opción 1: Abrir Localmente

```bash
# Clonar el repositorio
git clone https://github.com/king2000040909-collab/Inteligencia-artificial-.git

# Navegar al directorio
cd Inteligencia-artificial-

# Abrir en navegador
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

### Opción 2: Usar HTTP Server

```bash
# Con Python 3
python -m http.server 8000

# Con Python 2
python -m SimpleHTTPServer 8000

# Con Node.js (http-server)
http-server
```

Luego abre `http://localhost:8000` en tu navegador.

### Opción 3: GitHub Pages

La página puede ser hosteada en GitHub Pages automáticamente.

## 📞 Preguntas Frecuentes (FAQ)

### ¿Cómo puedo modificar los colores?
Edita las variables CSS en `:root` en `styles.css`

### ¿Funciona en navegadores antiguos?
Está optimizado para navegadores modernos. Para IE necesitarías polyfills.

### ¿Puedo usar esto como plantilla?
¡Por supuesto! Es código abierto bajo MIT.

### ¿Cómo integro datos reales de GitHub?
Necesitarás usar la API de GitHub con autenticación OAuth.
